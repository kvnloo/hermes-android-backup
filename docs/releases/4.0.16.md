# Ares 4.0.16

Stable release `4.0.16+3072`. ABI split codes `30721` (armeabi-v7a),
`30722` (arm64-v8a) and `30723` (x86_64), each above the highest published
4.0.15 split (`30713`). The production package `com.hermesagent.hermes_android`
and signing certificate are unchanged; install over the existing app.

## Added

- **NextGen chat menu for mouse and keyboard (#373).** On Windows and macOS the
  chat actions were only reachable by long-press. Right-click a chat row to open
  Pin/Unpin, Mark read/unread, Rename, Archive and Delete at the cursor, or use
  the ⋯ button shown on hover, keyboard focus and the open chat. Shift+F10 and
  the menu key open it on a focused row. Android long-press and row layout are
  unchanged.
- **Suggested slash commands in NextGen (#374).** Typing `/` opens a box of
  matching commands with descriptions above the composer, as Hermes desktop
  does. Matches come from the gateway's `complete.slash` (including argument
  completions), with the cached command catalogue as fallback on older
  gateways. Tap, click, or Up/Down with Enter or Tab fills the composer without
  sending; Enter on a fully typed command still sends it.

## Install

Download the APK for your device from the release assets and install over the
existing app; do not uninstall or clear app data. The Google Play build
updates through Play.

## Verification

  CI on the release-prep commit.
- Release APKs are production-signed and verified against the established
  certificate, package, ABI and version-code gates by the release workflow.
