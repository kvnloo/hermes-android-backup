# Ares 4.0.15

Stable release `4.0.15+3071`. ABI split codes `30711` (armeabi-v7a),
`30712` (arm64-v8a) and `30713` (x86_64), each above the highest published
4.0.14 split (`30703`). The production package `com.hermesagent.hermes_android`
and signing certificate are unchanged; install over the existing app.

## Added

- **NextGen Projects (#304, #367).** More → Projects browses the selected
  connection and profile's projects, opens their chats and starts new chats in
  a project's folder.
- **Project picker on new chats (#367).** An empty NextGen chat names its
  project in the greeting, Kyllene-style; tap it to pick Home or a project with
  a folder. A deliberate pick sends `cwd` with `cwd_explicit: true`. Gateways
  from before that field existed reject it and the app shows the error rather
  than starting the chat in the wrong folder.
- **Slash command highlight and usage card (#369).** Both composers colour a
  recognised leading command as it is typed; tapping it shows a small card with
  its description and usage from the gateway's catalogue.
- **NextGen runs slash commands (#370).** `/new`, `/reset`, `/stop` and `/model`
  are handled in the app; everything else runs through `slash.exec`, falling
  back to `command.dispatch` only on a definite refusal. Output shows on a
  command card. A lost reply is never resent.
- **Android Auto notification replies (#356).** Contributed by
  @davidKooreman. Completed replies post as car-compatible `MessagingStyle`
  conversations with reply and mark-as-read actions, bound to the existing
  chat. No launcher, TV, boot or auto-send changes.

## Fixed

- **Refused slash commands (#303, #302).** Contributed by @Thaeland. Commands
  the gateway refuses show a refusal card and keep the draft instead of being
  sent to the model as prose.
- **Repeat alerts after answering elsewhere (#371).** A question or approval
  answered on another device no longer re-notifies on Android or keeps its
  yellow highlight; the push companion's "answered" hint now names the request
  and clears the original notification.
- **Desktop composer (#363).** NextGen mic and send sit flush right on wide
  Windows and macOS windows.
- **NextGen chat list (#362, #364).** Internal runs are excluded; the selected
  profile's Show subagents setting is respected.
- **Canonical gateways (#84, #366).** Stop and Steer carry the running turn's
  execution generation; NextGen replay uses the session's replay epoch and
  reconciles on return to the foreground. Full durable recovery remains open
  in #84.
- **CI (#360, #361, #365).** Shared Robolectric version and runtime cache;
  deterministic root-navigation test.

## Dependencies (#368)

Gradle 9.9.2, AGP 9.5.2, embedded relink Kotlin 2.4.21 and coroutines 1.11.0,
`flutter_riverpod` 3.5.0, push companion `cryptography` 50.0.2,
`actions/setup-java` v6, `actions/cache` v6, `gradle/actions/setup-gradle` v6
with proprietary caching disabled. `xml` 7.1 (#332) and `intl` 0.20.3 (#329)
wait for a Flutter SDK upgrade.

## Install

Download the APK for your device from the release assets and install over the
existing app; do not uninstall or clear app data. The Google Play build
updates through Play.
