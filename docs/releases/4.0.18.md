# Ares 4.0.18

Stable release `4.0.18+3074`. ABI split codes `30741` (armeabi-v7a),
`30742` (arm64-v8a) and `30743` (x86_64), each above the highest published
4.0.17 split (`30733`). The production package `com.hermesagent.hermes_android`
and signing certificate are unchanged; install over the existing app.

## Removed

### In-app update check and APK installer (#379)

Ares is published on Google Play and F-Droid, so the app no longer looks after
its own updates.

- **No release check.** The app does not contact GitHub Releases on launch and
  shows no "Update available" prompt.
- **No installer.** It does not download an APK or open the Android installer.
- **Settings → About** no longer has **Check for updates** or **Check for
  updates on launch**.
- **Permission removed.** `REQUEST_INSTALL_PACKAGES`, the update file provider
  and the GitHub-only network security rules are gone from the Android app.
- **Clean-up.** An APK that an earlier version downloaded and left in the app
  cache, and the update check's saved state, are deleted on first launch.

The check also ran in builds outside Android, where it offered APK
instructions that did not apply.

## Changed

- Configuration backups no longer include the two update preferences. A backup
  made by an earlier version still restores; those two entries are skipped.
- The [privacy policy](../../PRIVACY.md) no longer describes an update request
  to GitHub, because the app makes none.

## Getting updates from now on

- **Google Play or F-Droid:** the store updates the app.
- **GitHub APK:** download the APK for your device from the
  [releases page](https://github.com/rusty4444/ares/releases) and install it
  over the existing app. 4.0.17 and earlier will offer this version once;
  after that the app stays quiet, so watch the repository's releases if you
  want to hear about new versions.

## Install

Download the APK for your device from the release assets and install over the
existing app; do not uninstall or clear app data. The Google Play build
updates through Play.

## Verification

- `flutter analyze --no-pub --fatal-infos` and the full `flutter test --no-pub`
  suite pass in CI on the release-prep commit.
- Release APKs are production-signed and verified against the established
  certificate, package, ABI and version-code gates by the release workflow.
- Not verified on a device or emulator.
