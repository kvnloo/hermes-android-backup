# Ares 4.0.17

Stable release `4.0.17+3073`. ABI split codes `30731` (armeabi-v7a),
`30732` (arm64-v8a) and `30733` (x86_64), each above the highest published
4.0.16 split (`30723`). The production package `com.hermesagent.hermes_android`
and signing certificate are unchanged; install over the existing app.

## Added

- **Parked Android Automotive preview (#376).** Isolated packaging for the
  Android Automotive target under the existing Ares application id, with
  driver-display checks and text-first preview handling across media and
  update boundaries. The phone release is unchanged; the preview is parked
  behind the Automotive-only policy and is not published to either Play track.

## Install

Download the APK for your device from the release assets and install over the
existing app; do not uninstall or clear app data. The Google Play build
updates through Play.

## Verification

- `flutter analyze --no-pub` and the full `flutter test --no-pub` suite pass in
  CI on the release-prep commit.
- Release APKs are production-signed and verified against the established
  certificate, package, ABI and version-code gates by the release workflow.
