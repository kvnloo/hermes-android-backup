# Ares 4.0.14

Stable release `4.0.14+3070`. ABI split codes `30701` (armeabi-v7a),
`30702` (arm64-v8a) and `30703` (x86_64), each above the highest published
4.0.13 split (`30693`). The production package `com.hermesagent.hermes_android`
and signing certificate are unchanged; install over the existing app.

## Fixed

### German NextGen copy corrected (#359)

The German catalogue carried Spanish wording through the NextGen screens.
`lib/l10n/app_de.arb` now carries real German copy, with the generated
`app_localizations_de.dart` regenerated to match and regression tests
(`test/l10n_de_ng_regression_test.dart`) asserting the fix.

## Install

Download the APK for your device from the release assets and install over the
existing app; do not uninstall or clear app data. The Google Play build
updates through Play.

## Verification

- `flutter analyze --no-pub` and the full `flutter test --no-pub` suite pass on
  the release-prep commit.
- The German regression test (`test/l10n_de_ng_regression_test.dart`) asserts
  the app_de catalogue carries German, not Spanish, copy.
- Release APKs are production-signed and verified against the established
  certificate, package, ABI and version-code gates by the release workflow.
