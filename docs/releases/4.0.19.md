# Ares 4.0.19

Stable release `4.0.19+3075`. ABI split codes `30751` (armeabi-v7a),
`30752` (arm64-v8a) and `30753` (x86_64), each above the published 4.0.18
splits (`30743`). The production package `com.hermesagent.hermes_android`
and signing certificate are unchanged; install over the existing app.

## Changed

### Chat model pickers list only configured providers (#381)

Both Classic and NextGen chat windows now list only the LLMs from providers
you actually configured on the gateway, instead of dumping the whole provider
catalog.

- A provider counts as configured when the gateway flags it
  `is_user_defined` or `is_current`, or when the row is a managed local
  runtime model or a virtual MoA row.
- A session pinned to a model from a hidden provider keeps that exact
  provider/model pair visible and selected, so you can leave the model where
  it is with one action. The pinned pair is kept, never the whole hidden
  provider, and rows that no longer exist in the inventory are not shown.
- If the gateway sends no flags at all, or the filter would leave the picker
  empty, the picker falls back to the full list — an empty picker is worse
  than an overfull one.

The cron picker, the model management screen and the NextGen models page
keep the full catalog; those are management surfaces where you need
everything.

## Install

Download the APK for your device from the release assets and install over the
existing app; do not uninstall or clear app data. The Google Play build
updates through Play.
