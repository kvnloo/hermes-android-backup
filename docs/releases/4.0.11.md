# Ares 4.0.11

Stable patch release `4.0.11+3067`. ABI split codes `30671` (armeabi-v7a),
`30672` (arm64-v8a) and `30673` (x86_64), each above the highest published
4.0.10 split (`30663`). The production package `com.hermesagent.hermes_android`
and signing certificate are unchanged; install over the existing app.

## Fixed

### The transcript scrolls to the end when the keyboard opens (#300)

Opening the composer keyboard mid-conversation left the last message behind
the keyboard with no scroll, forcing a manual scroll to reply. The keyboard
rise now triggers one composer-focused, edge-triggered end-scroll, re-armed on
the keyboard-drop reset. Parked readers stay put when a dialog steals focus,
and the stream re-arm still follows the last reply.

### `/new` starts a fresh session locally like the desktop (#301)

Typing `/new` and hitting send used to route to the slash worker's headless
`slash.exec`, which answered "cancelled, no input". The bare `/new` command
(and the `/reset` registry alias) is now intercepted in the local dispatch
path, before any gateway round trip, and pushes a fresh ChatScreen carrying
the parent's model, project name and working directory — the same shape the
desktop produces. Gateway-owned commands are unchanged.

## Install

Download the APK for your device from the release assets and install over the
existing app; do not uninstall or clear app data. The Google Play build
updates through Play.
